# Fonte de Informação e Banco de Dados

## 📊 Projeto PROCON

Este projeto tem como objetivo explorar e compreender dados abertos do PROCON com foco em identificar padrões, tendências e indicadores relevantes sobre denúncias e conflitos de consumo. A análise foi estruturada para transformar dados brutos em informações úteis para tomada de decisão e entendimento do cenário de consumo.

### Objetivo geral
- Explorar e organizar os dados do PROCON;
- Visualizar indicadores relevantes em dashboard;
- Identificar regiões, categorias e recorrências nas denúncias;
- Transformar dados brutos em informações estratégicas para análise.

### Fonte dos dados
- Arquivo principal: `Procon-Dadosdenuncia.xlsx`
